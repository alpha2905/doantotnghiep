                              🚀 KHỞI ĐỘNG NHANH
═══════════════════════════════════════════════════════════════════════════════

Cách 1: Chạy script tự động (Windows):
    start.bat

Cách 2: Chạy thủ công:
    1. Khởi động MongoDB:
       mongod

    2. Khởi động Backend (Terminal 1):
       cd backend
       python main.py
       # hoặc
       uvicorn main:app --reload

    3. Mở Frontend:
       cd frontend
       Mở file index.html trong trình duyệt
       # hoặc
       npx live-server --port=3000

                              🕷️ CRAWL DỮ LIỆU
═══════════════════════════════════════════════════════════════════════════════

Crawl thủ công:
    FPT Shop:
        python fpt_crawl/fpt_crawl_ip.py      # iPhone
        python fpt_crawl/fpt_crawl_ss.py      # Samsung
        python fpt_crawl/fpt_crawl_oppo.py    # OPPO
        python fpt_crawl/fpt_crawl_xiaomi.py  # Xiaomi

    Thế Giới Di Động:
        python tgdd_crawl/tgdd_crawl_ip.py
        python tgdd_crawl/tgdd_crawl_ss.py
        python tgdd_crawl/tgdd_crawl_oppo.py
        python tgdd_crawl/tgdd_crawl_xiaomi.py

    Điện Máy Xanh:
        python dmx_crawl/dmx_crawl_ip.py
        python dmx_crawl/dmx_crawl_ss.py
        python dmx_crawl/dmx_crawl_oppo.py
        python dmx_crawl/dmx_crawl_xiaomi.py

Crawl tự động (Scheduler):
    python scheduler.py              # Chạy menu tương tác
    python scheduler.py --mode auto  # Chạy tự động
    python scheduler.py -m once -p fpt   # Crawl một lần FPT
    python scheduler.py -m once -b iphone  # Crawl một lần iPhone
